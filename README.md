# Pocket Pong

The original rally, cut down to pocket size.

Paddle game arcade game. Drag your paddle. First to five points wins.

## Play and host

Double-click index.html to play locally after extracting the ZIP. The game is bundled into that file and does not require a local server. For GitHub Pages, enable Settings → Pages → GitHub Actions. The included workflow publishes the standalone game.

Expected URL after deployment: https://kofidon99.github.io/pocket-pong/

## YouTube

Upload the contents of youtube/ as a separate Playables bundle, with index.html at its root. This is a pitch build, not a certified release. SDK testing, real Android/iOS checks, metadata and platform review are still required. No licensed team or vehicle branding is included.
